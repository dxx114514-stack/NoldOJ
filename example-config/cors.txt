# CORS 配置
# ------------------------------------------------------------
# CORS_RESTRICTED: 是否启用跨域白名单限制
#   true  启用限制（默认）——仅允许下方列出及内置本机地址（localhost / 127.0.0.1）
#         携带凭据访问 API，其余来源一律拒绝。
#   false 放开限制——反射任意 Origin 并允许携带凭据。
#         适用于 OJ 题面使用 @[url](URL) 内嵌的外部网页需要跨源调用 OJ API 的场景
#         （例如嵌入一个带分析/提交功能的自建页面）。
#
# 安全说明：
#  - 放开限制后，凭据仍受双重约束：认证 Cookie 为 SameSite=strict（跨站不自动携带），
#    Bearer Token 存于 localStorage（第三方页面无法读取），因此第三方页面无法静默盗用登录态。
#  - 若运行环境完全可信、且确认无开放公网反向代理，再考虑置为 false。
# ------------------------------------------------------------

CORS_RESTRICTED=true

# 白名单：每行一个允许跨域访问的源地址（去掉末尾 /），以 # 开头为注释行
# 仅当 CORS_RESTRICTED=true 时生效。

# http://192.168.1.100:3000
# https://oj.example.com
