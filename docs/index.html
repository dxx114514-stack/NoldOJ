Security

纵深防御的安全沙箱

基于 Windows 原生 Job Objects 构建的多层隔离，让不可信代码在受控环境中运行。

01

进程树隔离

CREATE_SUSPENDED + Job Object 绑定，杜绝竞态逃逸。

02

强制回收

KILL_ON_JOB_CLOSE，主进程结束则整棵进程树被系统强制秒杀。

03

禁止脱离

禁用 BREAKAWAY，子进程无法脱离沙箱。

04

权限降级

受限令牌剥离 SeDebug / SeImpersonate 等高危特权。

05

资源限制

内存上限、CPU 时间限制、进程数限制双重保障。

06

数据隔离

每次判题独立临时目录，结束后暴力删除。

FAQ

常见问题

代码提交后一直显示"评测中"？

检查服务器控制台是否有报错。可能是编译器未安装或路径未配置。

内存显示 0KB？

沙箱模式下内存由 Job Object 测量。若显示 0KB，说明 sandbox_runner.exe 构建失败并回退到传统模式（该模式不测量内存）。确认 backend/sandbox/sandbox_runner.exe 存在（缺失时 start.bat 会自动从源码构建）。

如何在题目描述中使用公式？

行内公式用 $E=mc^2$，块级公式用 $$\sum_{i=1}^{n} i$$。

如何嵌入视频 / 网站？

Bilibili 用 @[bilibili](BV号)，任意网站用 @[url](URL)，音频 @[audio](URL)，视频 @[video](URL)。

AI 代码安全审查如何配置？

编辑 config/ai.txt，将 AI_ENABLED 设为 true，通过 URL 设置服务地址（默认 http://localhost:11434/api/chat），MODEL 设置模型名称（默认 qwen3:1.7b）。

数据库在哪里？

默认位于 backend/data/winoj.db，SQLite 格式，由 Node 内置 node:sqlite 驱动（v1.8.0 起），零数据库依赖，重启后数据保留。
