1入门指南

五分钟跑起来你的第一个 OJ。

快速开始

推荐方式：下载一键安装包（411MB），自动配置 Node.js、MinGW、Python、Java、Git 和 NoldOJ 本体，无需手动安装依赖。
下载一键安装包 →
镜像站下载（按延迟排序）：ghproxy.net（默认）

Step 1安装依赖（手动安装时）

请先安装以下软件并加入系统 PATH：

  • Node.js ≥ 24.x（需内置 node:sqlite，运行后端服务）
  • MinGW-w64（C/C++ 编译，任意版本）
  • Git
  • Python 3 / JDK（可选，如需评测对应语言）
  • Ollama（可选，AI 代码安全审查，需加载 qwen3:1.7b 模型）

Step 2克隆并启动

cmd
git clone https://github.com/dxx114514-stack/NoldOJ.git
cd NoldOJ
start.bat

启动后浏览器访问 http://localhost:3000。首次启动会自动初始化数据库、编译沙箱运行器并生成默认配置。

管理员账号：admin，初始密码随机生成，首次启动时在控制台日志中显示一次（仅此一次）
登录后请立即修改管理员密码。
安全提示：本项目基于 Windows 原生 Job Objects 实现沙箱隔离，Windows 桌面系统并非为绝对隔离设计。请勿在存有核心机密或敏感数据的个人主力机上以公网暴露形式运行。建议部署在虚拟机或专用测试机中。

2功能使用手册

按角色介绍 NoldOJ 的全部功能。角色层级：用户 < 教师 < 管理员 < 超级管理员。

普通用户

注册与登录

  • 登录与注册需通过 SVG 图形验证码（4 位字符，点击图片可刷新，5 分钟有效，一次性使用）
  • 单 IP 每小时仅可注册 1 个账号
  • 登录后 Access Token 15 分钟有效，Refresh Token 7 天自动续期（HttpOnly Cookie）
  • 支持「忘记密码」（需在 config/email.txt 开启邮箱服务）

做题与提交

  • 题目列表支持按标签、难度、分类组合筛选，支持模糊搜索（忽略空格）
  • 题目详情支持 Markdown + KaTeX 公式、输入输出样例一键复制、提示说明
  • 提交代码前可选用在线 IDE 调试（审查 → 编译 → 运行三阶段实时状态）
  • 有未完成提交时禁止再次提交（同一时间只能有一个进行中的提交）
  • 每个测试点显示：耗时、峰值内存、退出码、详细错误说明

资料、Rating 与成就

  • Rating：编译错误 -2，新 AC +10；导航栏 Rating 每 30 秒自动刷新
  • 等级称号：从「新手」到「大师」；排行榜前三名金银铜牌标识
  • 资料页：个性签名、个人简介（Markdown + KaTeX）、成就墙、提交日历（365 天）、语言分布、AC 难度分布
  • 隐私开关：hide_achievements / hide_dashboard / hide_favorites 三个独立开关，开启后对其它普通用户隐藏
  • 题目收藏：题目详情页一键收藏，个人收藏页管理

比赛、题单与讨论

  • 比赛：可被教师邀请参赛或手动加入；排行榜按总分降序、耗时升序；前三名金银铜标识
  • 虚拟比赛：对已结束比赛发起虚拟参赛，独立计时与排行，不影响原比赛数据；同一比赛只能虚拟参加一次；关闭浏览器计时不停（以服务端时间为准）
  • 题单训练计划：查看公开题单，自动记录完成进度
  • 讨论 / 题解区：题目详情页讨论 Tab，支持发帖、楼中楼回复（两层嵌套）、编辑删除自己的帖子；内容经 DOMPurify 防 XSS

教师

题目管理

  • 创建 / 编辑 / 删除题目；删除题目后编号可被新题目复用，磁盘 testdata 目录同步清理
  • Markdown 描述、输入输出格式、提示（建议填写数据范围）
  • 测试点：内联添加、批量添加、文件上传（.in / .out）、编辑、删除
  • 测试分组（Subtask）：设置满分、聚合方式、依赖关系、计分脚本
  • 标签（预置 10 个算法标签，支持自定义）与 6 级难度（☆入门 ~ ★★★★★困难）
  • 一键重测任意提交

比赛管理

  • 创建 / 编辑 / 删除比赛，添加题目（含非公开题目），自定义别名与排序
  • 邀请用户参赛（邀请制），比赛状态自动判定（未开始 / 进行中 / 已结束）
  • 比赛排行榜冻结（封榜）与手动解冻；结束后自动发布题解
  • 比赛结束后一键对全部题目发起代码查重

内容与社区

  • 发布文章（可链接题目作为题解）、全局 / 比赛公告（可置顶）
  • 文件上传 / 图床：支持图片、文档，单用户默认 2GB 配额，上传后可用 URL 在 Markdown 中引用
  • 讨论管理：置顶、加精、标记官方题解（金色边框）、锁定讨论（比赛中只读）
  • 发起代码查重：对指定题目 Token + Jaccard 相似度分析，异步执行、进度可查

管理员 / 超级管理员

管理员

  • 管理权限低于自己或自己的用户：封禁 / 解封 / 强制登出（封禁时 Access & Refresh Token 立即失效）
  • 查看 15 分钟内活跃的在线用户
  • 删除任意提交记录（编号自动回收）、删除任意讨论

超级管理员

  • 全部管理员权限 + 修改角色、重置密码、免密登录（一键切换任意用户身份）
  • 语言管理：动态添加 / 编辑 / 禁用 / 删除编程语言，配置编译 / 运行命令（支持 {src}、{exe}、{workdir} 占位符）
  • 设置用户 Rating、调整单用户图床限额、删除用户（ID 自动回收复用）

所有配置均通过 config/ 目录下的配置文件管理，不使用环境变量。

配置文件

配置示例：example-config/ 目录提供全部配置文件的完整示例（含字段说明与默认值）。可直接 copy example-config\* config\ 后按需修改。config/ 已在 .gitignore 中忽略，不会提交密钥到仓库。jwt.txt 缺失时服务启动会自动生成强随机密钥。

沙箱编译与开关

编译沙箱运行器

cmd · 需 MinGW
cd backend\sandbox
build.bat

未编译时 start.bat 会自动编译；编译失败回退到传统模式（spawn），安全性较低。可用以下环境变量控制沙箱行为：

环境变量默认作用
NoldOJ_REQUIRE_RUNNER0=1 时沙箱运行器缺失即 fail-closed 拒绝判题
NoldOJ_NO_APPCONTAINER0=1 完全跳过 AppContainer 容器路径
NoldOJ_FORCE_CONTAINER0=1 无特权也尝试容器路径（仅管理员排查用）
NoldOJ_EXEC_MODE00/1 受限令牌+Low IL；2 裸进程（诊断）；3 受限令牌不带 CREATE_NO_WINDOW
NoldOJ_NO_LOWIL0=1 关闭 Low Integrity 降级
NoldOJ_NO_RELABEL0=1 跳过 workDir 完整性标签降级（排查用）
NoldOJ_ROOTexe 位置推导指定项目根目录（沙箱日志路径）
权限说明：以管理员 / 服务身份运行时额外启用 AppContainer（文件系统 + 网络隔离）；普通用户运行时自动回退到受限令牌 + Low Integrity + Job Object（仍具备进程隔离与高危特权剥离），不会裸奔执行。

低完整性级别 + Job Object + 受限令牌 三层隔离

新架构移除了 Sandboxie，改用 Windows 原生三层隔离：

  • 低完整性级别：workDir 强制标记为 LOW IL（no-write-up），禁止向高完整性对象写入
  • Job Object：进程树隔离、CPU/内存/进程数限制、KILL_ON_JOB_CLOSE 自动清理
  • 受限令牌：剥离 SeDebug/SeImpersonate 等高危特权、禁用 Administrators 等特权组
  • AppContainer（可选）：管理员/服务运行时尝试，文件系统+网络隔离，失败自动回退
  • 文件IO题目模式：problem_type = file_io 时强制 workDir 降为 LOW IL

已移除 Sandboxie：新架构无需安装 Sandboxie，无需配置 config/sandboxie.txt（该文件已废弃）。

数据库迁移（sql.js → node:sqlite）

v1.8.0 起数据库引擎由 sql.js（WASM 内存库）更换为 Node 内置 node:sqlite（原生同步直写，零依赖）。sql.js 导出的数据库文件本身就是标准 SQLite 格式，旧数据无需转换。

迁移步骤

  1. 停止服务（关闭 start.bat 窗口，避免文件占用）
  2. git pull 更新代码
  3. cd backend && npm install（无需安装数据库驱动，node:sqlite 为内置模块，要求 Node ≥ 24）
  4. （可选但推荐）运行 node scripts\migrate-sqlite.js：自动备份 + 完整性校验 + 数据统计
  5. start.bat 启动，initDB() 自动执行全部 schema 迁移
说明：数据库仍位于 backend/data/NoldOJ.db。迁移后目录会出现 NoldOJ.db-wal / NoldOJ.db-shm（WAL 模式，崩溃安全、读写更快），属正常现象，请勿手动删除。如需回滚，用备份覆盖 NoldOJ.db 即可。

安全部署建议

  • 建议部署在虚拟机或专用测试机，避免在存有敏感数据的个人主力机公网暴露
  • 首次登录后立即修改管理员密码；建议为教师 / 管理员使用独立强密码
  • 对外提供服务时建议前置反向代理（如 Cloudflare Tunnel，见 st.bat）并保持 CORS_RESTRICTED=true
  • 定期 git pull 保持版本更新，跟踪安全修复

5常见问题

按场景分类的故障排查与使用问答。

启动与安装

代码提交后一直显示「评测中」？

检查服务器控制台是否有报错。可能是编译器未安装或路径未配置（MinGW / Python / JDK 需在 PATH 中）。

内存显示 0KB？

沙箱模式下内存由 Job Object 测量；若显示 0KB，说明 sandbox_runner.exe 构建失败并回退到传统模式（该模式不测量内存）。确认 backend/sandbox/sandbox_runner.exe 存在（缺失时 start.bat 会自动构建），或手动运行 cd backend\sandbox && build.bat。

提示「安全沙箱运行器缺失」？

设置了 NoldOJ_REQUIRE_RUNNER=1 且 sandbox_runner.exe 不存在时会 fail-closed 拒绝判题。编译运行器或取消该环境变量即可。

非管理员运行 node 进程，判题会失败吗？

不会。普通用户运行时自动跳过 AppContainer，回退到受限令牌 + Low Integrity + Job Object，隔离与限制照常生效（唯一差异是评测代码可访问网络）。仅当受限令牌路径也失败时才 fail-closed 拒绝执行，绝不裸奔回退。

Sandboxie 隔离是什么？需要额外安装吗？

Sandboxie-Classic 提供文件系统重定向和网络阻断，与 Job Object（资源限制）+ 受限令牌/AppContainer（权限隔离）叠加形成三层防护。默认开启，安装了 Sandboxie 且 SbieSvc 服务运行中即自动生效。未安装时自动回退到 Job Object 模式，不影响判题。

功能使用

如何在题目描述中使用公式？

行内公式 $E=mc^2$，块级公式 $$\sum_{i=1}^{n} i$$。

如何嵌入视频 / 网站？

Bilibili 用 @[bilibili](BV号)；任意网站用 @[url](URL)（需 https）；音频 @[audio](URL)；视频 @[video](URL)。

@[url] 内嵌的网页显示空白？

确认目标地址为 https（CSP frame-src 仅放行 https）；确认浏览器无拦截；若为 X 平台类反嵌入站点，目标站可能通过 X-Frame-Options 禁止被 iframe 内嵌，无法绕过。

AI 代码安全审查如何配置？

编辑 config/ai.txt：AI_ENABLED 设为 true，URL 设置服务地址（默认 http://localhost:11434/api/chat），MODEL 设置模型（默认 qwen3:1.7b），可选设置 KEY。

自定义计分脚本怎么写？

使用 @变量 赋值、if/fi 条件判断（支持括号）、min() / max() / abs() 函数。详见本页「计分脚本」一节。

验证码是如何工作的？

svg-captcha 动态生成 4 位字符（排除易混淆 O/0/I/1），带干扰线和彩色噪点。一次性使用、5 分钟有效、点击刷新、大小写不敏感（自动转大写匹配）。开关：config/captcha.txt 的 CAPTCHA_ENABLED。

AI 提示（AI Hint）怎么用？

登录后进入题目页，对同一题提交失败 2 次以上，「AI Hint」按钮自动出现。点击即可获取方向性算法提示（不给完整代码）。每题 60 秒冷却。需管理员启用 AI（config/ai.txt 的 AI_ENABLED=true）。

AI 测试数据生成怎么用？

以教师或管理员身份进入管理面板 → 题目管理 → 编辑测试点时点击「🤖 AI 生成」。可指定正常用例数和边界用例数，AI 自动为题目生成测试用例并写入磁盘。需管理员启用 AI。

数据与安全

数据库在哪里？

默认 backend/data/NoldOJ.db，SQLite 格式，由 Node 内置 node:sqlite 驱动（v1.8.0 起），重启后数据保留。

如何修改某用户的图床限额？

以超级管理员登录，进入用户管理页面，编辑目标用户即可修改单文件大小限制与总存储空间。只能管理权限等级低于自己或自己的账号。

如何搜索题目 / 比赛 / 文章？

在列表页顶部搜索框输入关键词，支持模糊匹配并忽略空格，例如搜索 a+b 可匹配 A + B Problem。

如何添加新语言？

以超级管理员登录，进入「语言」管理页面，填写编译 / 运行命令即可。命令支持 {src}、{exe}、{workdir} 占位符。

虚拟比赛是什么？

对已结束的比赛发起「虚拟参加」获得私有实例，计时从点击「开始」起算，时长等于原比赛时长，不可暂停，关闭浏览器计时不停（以服务端时间为准）。提交计入虚拟排行但不影响原比赛数据，同一比赛只能参加一次。

代码查重如何使用？

教师及以上在题目管理点击「查重」即可发起；查重后台异步执行，报告页实时显示进度。结果按相似度排序：≥85% 高度相似（红）、≥70% 疑似相似（橙）。详情页并排对比两份代码，相同 token 高亮。
