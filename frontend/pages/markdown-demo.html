Markdown 语法

题目描述、试卷题面、公告、文章、讨论等位置都使用同一条渲染管线： renderMarkdown() → DOMPurify 白名单清洗 → KaTeX 公式渲染。下面每一条示例的右侧都是该管线的真实输出。

快速上手：左侧是 Markdown 源码，右侧是它在本站的实际渲染效果。想动手试，直接用下方的实时预览编辑器。 支持 Markdown 基础语法、表格 / 围栏代码块 / 任务列表、KaTeX 公式 以及本站特有的 多媒体嵌入语法；脚本与事件属性会被自动剥离。

实时预览

左边随便改，右边立即渲染。

一、基础语法

通用 Markdown 核心语法。

标题

井号数量对应 1–6 级标题，井号后需要空格。

强调、删除线与行内代码

加粗、斜体、删除线、行内代码可混排，行内代码里的符号不会被解析。

段落与换行

空行分段；同一段里单独换行会变成软换行（<br>）。

链接与图片

链接新窗口打开；图片自适应宽度。危险协议（javascript: 等）会被替换。

引用

支持多行引用，也支持嵌套引用。

无序列表与有序列表

-、*、+ 都可以做无序标记；有序列表用 1. 或 1)。缩进两格以上是续行。

任务列表

列表项写成 [ ] 或 [x] 就会渲染成复选框。

表格

第二行必须是分隔行；用 :---: / ---: / ---: 控制居中、右对齐、左对齐。

代码块

用三个反引号包裹，可标注语言；块内的所有符号都原样保留。

分隔线

单独一行的 ---、*** 或 ___。

二、扩展语法

NoldOJ 在标准 Markdown 之上增加的公式与嵌入能力。

行内公式（KaTeX）

两个美元符号包住行内公式，公式内部的 * _ 等符号不会被当成 Markdown 强调。

展示公式

双美元符号独占一行时居中显示为块级公式。

内嵌网页 @[url]

把任意 http/https 或站内相对地址嵌成 iframe，常用于嵌入题解页、外部文档。

ECharts 图表 @[echarts]

参数是一段 JSON 配置，交给本地 eCharts 渲染；JSON 非法时降级为代码块。

Mermaid 流程图

用 @[mermaid] 与 @[/mermaid] 包住流程图源码，适合写题解或判题流程说明。

原样透传的 HTML 标签

常用的行内标签会被保留（仍走白名单清洗），可用于排版细节。

三、嵌入语法速查

统一形如 @[类型](参数)。

写法 作用
@[url](地址)内嵌网页（http/https 或站内相对路径）
@[bilibili](BV号)内嵌 Bilibili 视频，例如 @[bilibili](BV1xx411c7mD)
@[video](地址)内嵌本地/远程视频播放器
@[audio](地址)内嵌音频播放器
@[office](https://...)预览 Office 文档（需公网可访问的 https 地址）
@[echarts](JSON)ECharts 图表，参数为一份 JSON 配置
@[mermaid] ... @[/mermaid]Mermaid 流程图/时序图/甘特图

四、安全与限制

危险内容会被自动剥离

输出统一经过 DOMPurify 白名单清洗：事件属性、危险协议都会被去掉（元素本身可能保留，所以右侧会出现加载失败的图片与空的内嵌框），下面是"看起来想攻击"的源码与真实结果。

暂不支持的写法

  • Setext 标题（用 === / --- 垫在文字下方）——--- 一律按分隔线处理
  • 自动链接 <https://example.com>
  • 脚注 [^1]、定义列表、\ 反斜杠转义
  • 行内 HTML 中的 <script>、on* 事件属性——会被 DOMPurify 整体移除
  • 围栏代码块的语法高亮（只按纯文本保留，不引入高亮库）
